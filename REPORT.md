## 1. Цель работы

Разработать форму создания статьи и представление Django, которое проверяет авторизацию пользователя, обрабатывает POST-запрос, проверяет обязательные поля и уникальность заголовка, сохраняет статью с текущим пользователем в качестве автора и открывает созданную запись.

## 2. Ход работы

1. В папку `lab5` скопирован проект `blog` из лабораторной № 4.
2. В `articles/urls.py` добавлен маршрут `article/new/` с именем `create_post`.
3. В `articles/views.py` добавлено представление `create_post`. Доступ к форме предоставляется авторизованным пользователям; анонимным пользователям возвращается HTTP 404.
4. При GET-запросе выводится `create_post.html`. При POST-запросе читаются поля `title` и `text`, удаляются лишние пробелы и проверяется заполненность.
5. Добавлена проверка дублирующегося названия без учёта регистра. Для корректного сравнения русских букв используется `casefold()` в Python, поскольку SQLite `iexact` не обеспечивает полноценное Unicode-сравнение. При ошибке форма выводится повторно с сохранением введённых значений. Для каждого незаполненного поля показывается отдельное сообщение рядом с полем; встроенная браузерная проверка отключена атрибутом `novalidate`, поэтому сообщения формирует представление Django.
6. Для корректных данных создаётся объект `Article`, автором которого назначается текущий пользователь. После создания выполняется перенаправление на страницу статьи.
7. В шаблоне использован POST-метод и тег `{% csrf_token %}`. Поля формы и сообщения об ошибках оформлены с помощью `article.css`.
8. Для предотвращения совпадающих заголовков добавлена уникальность поля `Article.title` на уровне модели и миграция базы данных.
9. Добавлены автоматические тесты формы: доступ для анонимного пользователя, GET для авторизованного пользователя, успешное создание записи, пустые поля с отдельными сообщениями рядом с каждым обязательным полем и повторяющийся заголовок.

## 3. Проверка работы

После применения миграций выполнить `python manage.py check` и `python manage.py test articles`. Затем войти под пользователем и открыть `/article/new/`. Создать несколько статей, попробовать оставить обязательное поле пустым и повторить существующий заголовок. Проверить, что каждая успешная запись появляется в архиве и открывается на своей странице.
