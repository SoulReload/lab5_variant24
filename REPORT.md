## 3. Реализация формы создания статьи

Для создания публикаций разработана отдельная страница, доступная по адресу `/article/new/`.

Страница содержит поле для ввода названия статьи, многострочное поле для ввода текста и кнопку сохранения. Для отправки данных используется метод POST. В форму добавлен шаблонный тег `{% csrf_token %}`, обеспечивающий защиту от подделки межсайтовых запросов.

При первом обращении к странице представление отображает пустую форму. После отправки данных выполняется проверка введённых значений.

## 4. Проверка авторизации и данных

Создание публикаций доступно только авторизованным пользователям. При попытке обращения неавторизованного пользователя к представлению создания статьи возвращается ошибка HTTP 404.

Перед сохранением проверяется, что название и текст статьи заполнены. Если одно из полей не заполнено, пользователю отображается сообщение об ошибке, а введённые значения сохраняются в форме.

Также реализована проверка уникальности названия статьи без учёта регистра букв. Если статья с таким названием уже существует, сохранение не выполняется и пользователь получает сообщение с предложением выбрать другое название.

При успешной проверке создаётся новая запись модели Article. В качестве автора устанавливается текущий авторизованный пользователь. После сохранения пользователь перенаправляется на страницу созданной статьи.

## 5. Оформление формы

Для оформления страницы создан и подключён CSS-файл. С его помощью настроены размеры полей ввода, отступы, шрифты, оформление кнопок и расположение элементов формы.

Поле названия предназначено для однострочного ввода, а многострочное поле позволяет удобно вводить текст публикации. Также предусмотрена возможность изменения высоты текстового поля и адаптация оформления для небольших экранов.
