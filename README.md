# Лабораторная работа № 5 — форма создания статьи

**Вариант 24:** анализ динамики показателей финансовой отчётности предприятий холдинга.

Проект создан на основе `blog` из лабораторной № 4. Добавлены маршрут `/article/new/`, авторизованное представление `create_post`, HTML-форма с CSRF-токеном и CSS-оформление. Автор записи определяется автоматически по вошедшему пользователю. Пустые поля и повторяющиеся заголовки отклоняются.

## Запуск в Windows PowerShell

Выполняйте команды в корневой папке `lab5`:

```powershell
python -m pip install -r requirements.txt
cd blog
python manage.py migrate
python manage.py check
python manage.py test articles
python manage.py createsuperuser
python manage.py runserver
```

Виртуальное окружение для выполнения этих команд не обязательно: используйте Python, в котором установлен Django. Если администратор уже существует, `createsuperuser` повторять не нужно. Для изоляции зависимостей виртуальное окружение можно создать дополнительно, но для этой лабораторной оно не требуется.

## Как проверить лабораторную

1. Откройте `http://127.0.0.1:8000/admin/` и войдите под администратором. Создайте минимум одного пользователя, которому разрешите вход на сайт (обычный пользователь подходит).
2. Войдите как этот пользователь через `/admin/` (для учебной демонстрации можно использовать суперпользователя).
3. Перейдите в архив `http://127.0.0.1:8000/`. Для авторизованного пользователя должна появиться ссылка «Написать статью».
4. Откройте `http://127.0.0.1:8000/article/new/`, заполните название и текст и сохраните запись. После сохранения произойдёт переход на созданную статью.
5. Попробуйте отправить форму с пустым названием или текстом — должно появиться сообщение об ошибке, а введённые значения сохранятся в форме.
6. Попробуйте создать статью с уже существующим названием (даже с другим регистром букв). Запись не должна сохраниться, а форма покажет сообщение о дублирующемся названии.
7. Откройте архив и убедитесь, что новые статьи появились в списке.
8. Выйдите из учётной записи и снова откройте `/article/new/`: анонимный пользователь должен получить 404.

## Адреса

- `/` — архив статей;
- `/article/new/` — форма создания статьи (только для авторизованного пользователя);
- `/article/<ID>/` — страница существующей статьи;
- `/admin/` — административная панель;
- `/finance/` — сохранённая финансовая сводка варианта 24.

## Проверки и безопасность

- Проверяются авторизация, обязательность полей, уникальность заголовка без учёта регистра и автоматическая привязка автора.
- CSRF-защита включена через `{% csrf_token %}`.
- Заголовок дополнительно уникален на уровне модели/базы данных; миграция `0002_article_title_unique.py` меняет соответствующее поле.
- Локальная база, резервные копии, `.env`, виртуальные окружения и кэш Python исключены через `.gitignore`. Не храните реальные финансовые данные или пароли в репозитории.
